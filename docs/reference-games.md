# 커리어 시뮬레이션 화면 참고

사용자가 기존의 노트형 웹 UI와 픽셀·일러스트·만화풍 방 시안을 모두 거절하고, **벤치에서 발롱까지 같은 게임을 먼저 확인할 것**을 요청했다. 아래는 실제 화면에서 본 내용과 공식 설명을 구분해 기록한다. 참고 게임의 그림·로고·문구를 우리 게임 자산으로 복제하지 않는다.

## 벤치에서 발롱까지

- 공식 게임: https://kickru.com/
- 공식 가이드: https://kickru.com/guide
- 직접 확인: 새 선수의 아바타 선택 → 이름·포지션 등 설정 → 집중 육성 능력 선택 → 고1 첫 시즌 → 시즌 결과 → 커리어 홈 → 다음 진로 화면.
- 화면: 밝은 바탕과 흰 패널, 작은 도트 선수 아바타, 나이·소속·종합 능력치와 직전 시즌 대비 변화가 프로필에 함께 표시된다.
- 진행: 현재 확인할 일, 다음 진로, 집중 육성 항목이 명확하게 보인다. 홈·반응·시즌·선수·기록 하단 메뉴로 정보를 분리한다.
- 결과: 출전·득점·평점·능력 변화와 대회 성적이 숫자로 정리된다. 큰 방 일러스트를 감상하는 화면이 게임의 중심은 아니다.
- 공식 설명: 성장에는 나이·출전 시간·활약·건강·숨겨진 특성이 영향을 주며, 자동 저장과 커리어 파일 보관을 지원한다.

## 이번 생은 야구다

- 공식 게임: https://slbcareer.com/
- 직접 확인: 홈 → 웹에서 계속하기 → 새 인생 → 선수 생성 화면. 시즌 내부 플레이까지 확인한 것은 아니다.
- 홈: 세로 모바일 게임 화면, 구장 배경과 강한 제목 그래픽, 큰 시작 버튼, 하단 홈·클럽하우스·플레이볼·랭킹·상점 메뉴.
- 생성: 어두운 구장 헤더 아래 국적·이름·등번호·선수 유형 등을 선택하는 패널. 일반 사이트의 소개 섹션 대신 플레이어의 설정과 다음 행동이 중심이다.

## 랜덤입사게임

- 공식 설명: https://excelkospi.pages.dev/random-hire
- 개발자 공지: https://excelkospi.github.io/patch-notes
- 확인 범위: 공식 설명과 공지 원문. 실제 플레이 내부 화면을 직접 관찰했다고 해석하지 않는다.
- 공식 공지는 진행 화면을 사원증·능력치·통장, 가운데 기록, 통계·동기·근속 지도로 구성한다고 설명한다. 결과는 경력증명서와 요약 지표로 보여준다.

## 우리 게임에 적용할 방향

1. 큰 방 배경이나 그림체 선택보다 **플레이어 프로필·육성·현재 결정·누적 기록**을 먼저 설계한다.
2. 작은 인물 아바타와 직업·나이에 따른 상태, 수치 변화, 다음 목표를 지속적으로 보여준다.
3. 생활·일정·인연·진로·기록을 게임 메뉴로 나누고, 큰 소개 문구와 장식적인 인용문은 줄인다.
4. 이번 달 루틴 → 한 달 진행 → 결과와 만남 → 중요 사건 → 다음 계획의 반복이 게임의 중심이다.
5. 사용자가 이미 요청한 월간 학생 일정과 능력·행복·관계 변화는 유지한다. 스케줄을 조정하는 재미를 자동 진행으로 대체하지 않는다.

이 문서는 조사 근거와 적용 방향을 기록한다. 현재 구현 범위와 실행 방법은 [README](../README.md)를 따른다.
