# 현실 자료 조사 계획

게임의 현실감을 만드는 자료와 재미를 위한 창작 설정을 분리한다. 조사한 숫자는 출처와 기준을 설명할 수 있어야 한다. 자료가 없는 세부 분야를 실제 통계가 있는 것처럼 채우지 않는다.

## 현재 확인한 범위

[커리어넷 직업백과](https://www.career.go.kr/cloud/w/job/list)에 직업별 평균연봉 항목이 존재하는 것을 확인했다. 아직 개별 직업의 금액, 조사 연도, 조사 대상, 세전 여부와 재사용 조건은 검증하지 않았다.

다른 공공 통계 사이트는 이 환경에서 접속 오류가 발생해 원문을 확인하지 못했다. 접근 실패를 자료가 없다는 뜻으로 해석하지 않는다. 현재 게임 예시값은 검증된 현실 연봉 자료가 아니다.

## 수집할 자료

| 분야 | 확인할 내용 |
|---|---|
| 진로와 교육 | 하는 일, 세부 분야, 대표 진입 경로, 자격·학위, 준비 기간과 비용 |
| 임금근로 | 신입과 경력별 임금, 고용 형태, 기업 규모, 지역, 상여 포함 여부 |
| 창작·프리랜서 | 계약·프로젝트별 수입, 연간 활동 소득, 제작비·수수료, 수입 공백 |
| 사업 | 업종·규모별 매출, 원가·인건비·임대료, 손익과 현금 흐름 |
| 실제 생활 | 입문 교육, 직무 배치, 시즌과 계약 주기, 업무 역할과 경력 전환 |

국가·공공기관의 조사와 방법 설명을 먼저 확인하고, 업종별 보고서·직능단체 자료·채용 공고·공개된 조직 안내로 보완한다. 공고의 제시 급여와 실제 재직자 소득은 다른 지표로 기록한다. 후기 한 건으로 특정 직업이나 규모의 회사를 일반화하지 않는다.

## 연봉을 기록하는 기준

임금근로자의 비교 기준은 우선 **세전 연간 임금, 한국 원화**로 잡는다. 원문이 다른 기준이면 원래 값과 변환 과정을 보존한다. 세전 여부가 명확하지 않다면 확인되지 않았다고 표시한다.

- 직업 전체 평균을 신입 초봉으로 사용하지 않는다.
- 평균, 중앙값과 분위값은 서로 다른 지표다. 출처의 표현을 그대로 기록한다.
- 조사 연도와 발표 연도를 구분한다. 오래된 금액을 현재 금액처럼 표시하지 않는다.
- 월급을 연봉으로 바꿀 때 상여·성과급과 조사 기간을 확인한다. 퇴직금, 주식 보상, 수당의 포함 여부도 남긴다.
- 경력, 기업 규모와 고용 형태가 다른 자료를 동일한 집단의 통계처럼 합치지 않는다.
- 조사에 없는 성공 확률이나 소득분포를 평균·분위값만으로 만들어내지 않는다.

창업자의 매출은 개인의 연봉이 아니다. 사업 수입과 비용을 나누고, 사업에 남겨두는 돈과 개인에게 가져오는 돈도 구분하는 방향으로 설계한다. 창작자와 프리랜서도 활동 소득과 비용을 확인한다.

## 자료마다 보존할 정보

| 항목 | 예시 또는 설명 |
|---|---|
| 원문 출처 | 기관, 보고서·표 제목, 원문 주소와 해당 표·쪽 |
| 기간 | 조사 기준 연도·기간, 발표일, 확인일 |
| 대상 | 직업 분류, 국가·지역, 경력, 고용 형태, 기업 규모와 표본 범위 |
| 지표 | 평균·중앙값·분위값, 금액·통화·단위, 세전 여부와 포함 항목 |
| 변환 | 월→연 환산 등 계산 근거와 원래 값 |
| 품질과 한계 | 표본 수, 누락 범위, 다른 자료와 비교 가능한지 |
| 재사용 조건 | 이용허락·라이선스, 출처표시, 재배포 가능 범위 |
| 게임 적용 | 관측값인지 추정값인지, 어떤 항목에 쓰는지 |

현실의 직업 분류와 게임의 세부 진로는 별도로 연결한다. 예를 들어 특정 세부 개발 직무의 자료가 없어서 상위 직군을 참조했다면, 원래 분류와 대체 이유를 기록한다. 세부 분야에 직접 조사한 금액으로 표시하지 않는다.

## 창작 설정과의 경계

실제 조사값은 원본 자료로 보관하고, 게임 보정은 별도로 관리한다. 월별 사건 확률, 능력치 효과, 승진 조건, 가상의 사람과 회사는 게임 설정이다. 조사값에서 자동으로 도출된 사실처럼 설명하지 않는다.

시대·지역·회사별로 차이가 큰 제도는 특정 사례를 모든 경로의 규칙으로 고정하지 않는다. 변화가 필요한 자료는 기준 연도를 갱신하고, 갱신에 따른 게임 균형 변화도 별도로 확인한다.

## 수집과 검토 절차

1. 예시 경로마다 대표 직무를 정하고, 현실 직업 분류와 연결한다.
2. 원문과 조사 방법, 재사용 조건을 확인한다. 공공기관 자료라고 무조건 재배포할 수 있다고 가정하지 않는다.
3. 필요한 사실과 수치를 출처와 함께 기록한다. 문장을 대량 복제하지 않고 설명을 새로 작성한다.
4. 서로 다른 기준의 자료가 섞이지 않았는지 검토한다. 검증되지 않은 항목은 비워두거나 추정임을 표시한다.
5. 게임에 적용할 범위와 창작 보정값을 분리한 뒤 플레이로 균형을 확인한다.

실제 개인의 연봉, 회사 내부 인사 자료나 비공개 개인정보를 수집하지 않는다. 공개된 집계 자료와 허용된 자료를 활용하고, 등장인물은 가상으로 만든다.
