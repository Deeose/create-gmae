# 갈림길 — 인생 시뮬레이션

중학교 3학년부터 관심과 진로를 발견하고, 사람을 만나고, 자신이 원하는 삶을 만들어가는 선택형 인생 시뮬레이션.

**공통 인생과 직업별 생활을 분리한다.** 회사원에게는 연수·배치·업무·후배 교육이, 독립 창작자에게는 제작·공개·계약이, 가게 운영자에게는 개업·재고·고객·비용이 중요하다. 직업을 바꿔도 과거 경험과 사람은 남는다.

**브라우저에서 선택하며 플레이하는 웹 프로토타입**이다. 학교 시절부터 세 가지 생활 경로를 짧게 경험하고, 선택의 결과와 능력·관계·기억의 변화를 확인할 수 있다. 평생 분량의 콘텐츠와 세부 진로 전체는 앞으로 확장한다.

## 실행

Node.js 22 이상이 필요하다. 외부 패키지를 설치하지 않아도 된다.

```bash
git clone https://github.com/Deeose/create-gmae.git
cd create-gmae
npm start
```

웹 파일을 빌드하고 로컬 서버를 실행한다. 브라우저에서 `http://localhost:4173`을 열어 새 인생을 시작한다.

현재 실행 방법은 로컬 웹 서버 기준이며, 배포된 고정 플레이 주소는 아직 없다.

선택지를 누르면 결과를 확인한 뒤 다음 사건으로 진행한다. 학교 사건 이후 회사원·독립 창작자·가게 운영자 중 하나를 고를 수 있다. 능력치, 인간관계, 기억과 거래 기록을 살펴보고 마지막에는 지나온 선택을 돌아본다.

웹 진행은 **같은 브라우저의 로컬 저장소에 자동 저장**된다. 새로고침하거나 페이지를 다시 열면 이어할 수 있다. 계정이나 서버 동기화는 없으므로 다른 기기·브라우저·사이트 주소와는 저장을 공유하지 않는다. 브라우저의 사이트 데이터를 지우면 진행도 사라진다.

```bash
npm run build               # 배포용 정적 웹 파일을 dist/에 생성
npm run cli                 # 터미널에서 직접 선택
npm run cli -- --load        # 터미널 저장 이어하기
npm run demo -- employee    # 회사원 자동 재생
npm run demo -- creator     # 독립 창작자 자동 재생
npm run demo -- owner       # 가게 운영자 자동 재생
npm run validate            # 추가한 데이터의 참조·조건·진로 그래프 검사
npm test                    # 모든 예시 선택 조합과 저장·관계 보존 검사
```

터미널 모드는 번호로 선택하고, `q` 또는 입력 종료 시 `saves/slot-1.json`에 저장한다. 웹 자동 저장과 터미널 저장은 별개다. 자동 재생은 각 사건의 첫 선택지를 고른다.

시작은 15세이고, 학교 시절 세 사건 이후 원하는 생활 경로를 고른다. 모든 경로에 대학 진학을 강제하지 않는다.

## 들어 있는 구조

| 부분 | 이번에 확인할 수 있는 내용 |
|---|---|
| 공통 인생 | 나이, 과목별 실력, 건강·행복, 업무·대인 스트레스, 가치관 수치 |
| 웹 화면 | 직접 선택, 결과 피드백, 능력·관계·기록 확인, 자동 저장과 이어하기, 완주 회고 |
| 선택과 기억 | 조건부 선택지, 과거의 경험, 만난 사람과 관계 보존 |
| 회사원 | 입문 교육 → 부서 배치 → 첫 마감 → 3년 뒤 후배와 공로 문제 |
| 독립 창작자 | 작품 제작 → 직접 공개 또는 계약 → 의뢰·후속작·휴식 |
| 가게 운영자 | 개업 준비 → 거래처와 첫 고객 → 원가 상승 대응 |
| 경제 기록 | 급여, 작품·가게 매출, 비용을 각각 기록 |
| 데이터 | 사건 13개, 인물 10명, 가상 조직 3곳, 진로 그래프 16개 노드 |

예를 들어 학교 프로젝트에서 친구를 도왔다면 성인이 된 뒤 그 친구와 다시 협업하는 선택지가 열린다. 이미 만난 친구는 재회해도 관계나 성향이 초기화되지 않는다.

**모든 금액·기간·기관·인물은 구조 검증용 가상 설정이다.** 현실의 연봉·학비·창업비 조사는 아직 반영하지 않았다. 거래는 사건에 명시된 1회분만 계산한다. 몇 년을 건너뛰어도 정기 급여·생활비·세금이 자동으로 발생하지 않으므로 잔액을 장기 소득 시뮬레이션으로 해석하지 않는다.

## 파일 안내

```text
data/
  career-tree.json       관심 → 분야 → 세부 분야 → 직업, 여러 진입 경로
  tracks.json            생활 경로의 초기 단계·고유 지표·수입 방식
  events.json            발생 시점·조건·선택지·결과
  people.json            인물 성향과 첫 관계
  organizations.json     가상 조직의 설명과 문화
src/
  core/engine.js         공통 상태·사건·효과·관계·저장 형식
  core/session.js        다음 사건까지 시간 진행
  content/              JSON 읽기와 검증
  cli/                  선택형 플레이·자동 재생
web/
  index.html            브라우저 게임 화면
  app.js                선택·결과 화면과 브라우저 저장 연결
  styles.css            반응형 화면과 스타일
scripts/
  build-web.mjs         웹·공통 엔진·데이터를 dist/에 모으기
  serve.mjs             웹 빌드와 로컬 정적 서버
test/engine.test.js     이야기 연결과 핵심 규칙 검증
docs/
  game-design.md         지금까지 정한 게임의 방향
  architecture.md        데이터 구조와 확장 방법
  research-plan.md       진로·소득 자료 조사 기준
```

처음 코드를 볼 때는 [사건 데이터](data/events.json)의 `school-project`와 [공통 엔진](src/core/engine.js)의 `choose()`를 함께 읽으면 좋다. 선택을 받으면 어떤 데이터가 바뀌고 다음 선택지가 어떻게 열리는지 따라갈 수 있다.

웹 화면과 터미널은 같은 엔진과 사건 데이터를 쓴다. 화면을 고치기 위해 게임 규칙을 복제할 필요가 없다. 배포 결과물은 `dist/`이며, `index.html`과 함께 엔진·데이터 파일도 정적 호스팅에 올려야 한다.

## 다음 단계

- 세부 진로 그래프를 실제 선택 화면과 연결하고 과목·전공·학교의 기회를 구체화하기
- 경로마다 실제 생활 주기와 경제 계산을 구현하고, 회사별 교육·배치 일정 세분화하기
- 성향에 따른 반응, NPC의 입사·승진·이직과 조직 관계망 만들기
- 가치관 선택과 변화, 가치에 따른 인생 회고·결말 구현하기
- 조사한 소득 자료와 출처를 연결하고 연구자·운동선수·정치인 경로 확장하기

조직 문화는 현재 설명 데이터이며 자동으로 일정을 만들지 않는다. 진로 그래프는 연결 구조를 검증하지만 아직 단계별 선택 화면으로 구현되지는 않았다. 인물 성향은 첫 만남 때 고정 seed로 변주해 저장하고, 본격적인 성향별 반응과 자율 행동은 후속 작업이다.
